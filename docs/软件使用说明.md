# Anima List 使用说明

适用版本：v1.3.1

查看入口：设置页面最下方 → 使用说明。

Anima List 用于记录追番、补番进度，保存评分、观后感和单集感想。无需登录即可在本机使用，需要在手机和电脑之间同步记录时再注册云同步账号。

## 1. 第一次使用

首次在没有番剧记录的设备上启动时，会自动打开这份说明。目录默认折叠，点击“目录（点击展开）”即可展开，再点击章节名称跳转。关闭首次说明后，会提示以后可在设置页面最下方查看；之后启动不再自动弹出，手动打开时目录仍默认折叠。

1. 在主页点击添加按钮，输入番剧名称。
2. 在搜索结果中选择正确的作品和季度，检查自动填写的资料。
3. 选择“追番”或“补番”，填写已看集数，点击“保存”。
4. 看完一集后，在主页点击该番剧的“+1”。
5. 点击番剧卡片进入详情页，可以填写单集感想、星级和观看时间。

也可以点击主页设置按钮右侧的日历图标，从新番表中添加作品。

## 2. 添加和编辑番剧

### 通过名称搜索添加

在“添加番剧”页面输入名称，稍等即可看到搜索结果。点击所需条目后，软件会填写名称、总集数、放送日期等信息，并为追番尝试补充每周更新星期和具体时间。

选择结果时注意区分第一季、续作、剧场版等不同条目。填写完成后仍需点击右上角“保存”。

### 手动添加

没有找到合适结果时，可以直接填写名称、总集数和已看集数，再保存。追番可填写放送日期、更新星期和具体时间；补番可填写放送日期、开始观看日期和看完日期。

具体更新时间使用 `HH:MM` 格式，例如 `22:00`。深夜档支持 `24:00` 至 `29:59`；例如 `25:30` 表示次日凌晨 1:30，列表仍按该作品所标注的更新星期归类。

### 修改已有作品

在主页向左滑动番剧卡片，点击齿轮编辑图标；电脑端也可以用鼠标向左拖动。还可以进入详情页，点击顶部朝右上的扳手图标。

修改资料后点击“保存”。编辑页也可以搜索并重新选择关联作品。

## 3. 使用新番表

点击主页的日历图标打开新番表，分别选择年份和季度。列表按周一至周日分组，尚未公布更新星期的作品显示在“时间待定”中。

- 点击“加入待看”，软件会先匹配完整番剧资料，成功后加入主页的想看列表。
- 添加后仍停留在新番表当前位置，按钮显示“已在待看列表”。已加入的作品不会重复添加。
- 如果没有匹配到合适条目，本次不会添加，可以回到主页通过名称搜索或手动添加。
- 预告阶段尚未公布的播出日期、具体时间和集数，可在资料完善后通过“设置 → 数据管理 → 更新番剧信息 → 更新全部”补充。

新番表从 2019 年秋季（10 月）开始收录；更早的季度显示“无数据”。未来季度是否有内容，取决于新番资料是否已经发布。

## 4. 追番、补番与季度归类

“追番”适合跟随新番播出进度观看，“补番”适合按自己的节奏观看已经积累的作品。

| 类型和状态 | 显示在哪个季度 |
| --- | --- |
| 追番，在看 | 随系统日期及预计播出进度跨季移动，最晚停在预计末集播出的季度 |
| 追番，已看完 | 回到首播季度 |
| 补番，在看 | 随系统日期显示在当前季度 |
| 补番，已看完 | 按看完日期归档 |
| 想看、搁置、放弃 | 按首播季度归档 |

追番的播出进度按首播日期、总集数和每周一集估算。追番采用新番档期划分，季末最后一周可能提前归入下一季度；补番按日历季度划分。

补番完成时会自动填写当天为看完日期。实际完成时间不同，可以在编辑页修改。旧记录缺少首播日或看完日期时，也可以在编辑页补全，帮助软件正确归档。

## 5. 记录观看进度和状态

- 在主页点击“+1”，已看集数增加一集。
- 在详情页使用“−”和“+”调整进度，也可以在编辑页调整已看集数。
- 已看集数为 0 时，状态自动显示为“想看”；达到总集数时，自动显示为“已看完”。
- 对尚未完成的作品，可以选择“在看”“搁置”或“放弃”。

总集数、放送日期等资料可在编辑页修正。达到预计总集数后，如果作品仍在更新，可先增加总集数，再继续记录进度。

## 6. 单集感想、星级和观看时间

进入番剧详情页，找到“集数记录”。这里每集一行，只展示第 1 集至当前已看集数。

- 在文本框内填写这一集的感想，内容自动保存，文本框会随文字增高。
- 点击星星记录该集的 1～5 星评分；再次点击当前选中的星级可取消评分。
- 增加观看进度时，新看集数会自动记录本次操作的时间。一次增加多集时，这些集数使用同一次操作时间。
- 点击“观看时间”可手动修改日期和时间，按设备当前时区显示。历史记录中未知的观看时间留空，标注“待补充”。
- 点击集数记录标题旁的“收起／展开”，可以折叠整个区域。
- 点击“跳到当前集”，会展开记录区并定位到最近已看的一集。

尚未观看任何一集时，可以先增加观看进度，再填写记录。减少进度后，超出当前进度的已有单集内容会暂时隐藏；仍在总集数范围内的内容会继续保留。

## 7. 整部评分和观后感

编辑番剧时，可以填写整部作品的评分与观后感。已看完的作品也可以直接在详情页点击顶部星级评分。

详情页下方的“观后感”用于保存对整部作品的感受，停止输入后自动保存。单集感想则写在对应集数的记录中。

## 8. 查找、筛选和折叠列表

主页搜索框按已保存的番剧名称查找作品。状态筛选可以切换“全部”“想看”“在看”“搁置”“已看完”“放弃”。

列表按年份和季度分组。点击年份或季度标题，可以收起或展开该组；软件会记住折叠状态。

在“设置 → 列表显示”中，可选择“封面模式”或“仅文字”。首次使用默认封面模式。

## 9. 设置展示次序

在“设置 → 番剧信息 → 展示次序”选择排序方式。排序作用于每个年、季度分组内的追番；补番按开始观看日期排列。

- **时间次序：**按照周一至周日固定排列，同一星期的作品按名称排列。
- **更新次序：**从所选起点向前排列最近的更新星期。同一天优先展示深夜、晚间、下午、上午；同一时段优先展示较晚的更新时间。时间待定的作品排在后面。

选择更新次序后，还可以设置“更新次序起点”：

| 系统当天为周三时 | 排列示例 |
| --- | --- |
| 当天为准 | 周三 → 周二 → 周一 → 周日 → 周六 → 周五 → 周四 |
| 昨天为准 | 周二 → 周一 → 周日 → 周六 → 周五 → 周四 → 周三 |

默认以昨天为准。点击“展示次序”旁的圆形说明按钮，也可以查看排序方法。

## 10. 设置启动提醒

打开“设置 → 启动提醒”，分别设置“显示当日更新”和“显示昨日更新”。两个选项可以同时开启；全部关闭时，启动不弹出追番提醒。

提醒根据设备的系统日期和作品的更新星期生成。“想看”及“在看”的追番，在预计播出周期内参与提醒；弹窗还会列出正在补番且未看完的作品。

默认开启当日更新、关闭昨日更新。这是打开软件时显示的提醒弹窗，软件关闭时不会发送系统通知。

## 11. 番剧资料、封面缓存和访问方式

### 查看与刷新资料

在“设置 → 番剧信息”开启“显示番剧具体信息”，详情页会展示已有的简介、制作人员、角色和声优等资料。关闭后，这些详细资料区域隐藏。

需要补充预告阶段资料或刷新现有作品时，使用“设置 → 数据管理 → 更新番剧信息 → 更新全部”。更新过程中会显示进度，单部作品失败不会中断其他作品。

更新全部会刷新名称、集数、放送日期和更新时间等资料，手工填写的这些资料也可能被来源信息更新；观看进度、评分、观后感和单集记录会保留。

### 离线使用

加入列表的作品会在后台保存简介、制作信息、封面地址和资料最后成功更新时间，并逐一缓存全部作品的缩略图，包括想看、已看完、搁置和放弃的作品。

首次使用需要联网等待后台补齐。之后断网时可以继续记录进度、评分和感想，并查看已经保存的资料与缩略图；联网后会继续补充或刷新资料。

### 直连与代理

在“设置 → API 接口 → Bangumi 访问方式”中选择：

- “直连”：先尝试直连，失败后自动尝试代理。
- “代理”：先尝试代理，失败后自动尝试直连。

搜索或资料加载持续失败时，可以切换访问方式后重试；已经保存在本机的观看记录可继续使用。

## 12. 导出与导入

### 导出记录

在主页或“设置 → 数据管理”打开导出功能，选择要导出的年份、季度，然后选择：

- **JSON 文件：**保存备份文件；手机端通过系统分享选择保存位置或发送到其他设备。
- **复制纯文字：**显示同一份 JSON 数据，点击复制后可保存到文本文件，或发送到其他设备用于导入。

导出的记录包含进度、评分、感想、单集观看时间及已保存的资料文本和封面地址；封面图片文件和软件设置不包含在这份 JSON 中。

### 导入记录

打开导入功能，选择 JSON 文件或粘贴 JSON 文字，检查导入数量，再选择处理方式：

| 方式 | 已有番剧如何处理 |
| --- | --- |
| 仅添加新番 | 不用导入内容替换已有番剧，只添加不存在的作品 |
| 保留本地 | 保留本地进度、评分与感想，只补充空缺资料，并添加新作品；默认选项 |
| 使用导入记录 | 同一作品的进度、评分和感想等使用导入内容 |

确认后，软件会先保存操作前备份，再导入记录，并在后台补齐缺失资料。单条资料补全失败，不会撤销已保存的导入结果。

## 13. 删除、撤销和自动备份

### 删除单部番剧

在主页左滑卡片，点击删除图标；也可以在详情页点击删除。确认删除后，提示条会显示“撤销”，15 秒内点击即可恢复这部作品。

### 清空列表

进入“设置 → 数据管理 → 清空所有番剧”，点击“清空全部”并确认。清空前自动保存一份非空列表备份。

### 恢复自动备份

在“设置 → 数据管理 → 自动备份（最近 3 份）”中，查看备份的操作名称、时间和作品数量，选择所需的一份，点击“恢复”并确认。

软件在导入、清空、云端数据替换本地、上传覆盖云端以及恢复备份前保存相应的旧记录。本机仅保留最近 3 份非空操作前备份，新的备份会替换最旧的一份。

自动备份保存在当前设备。清除应用数据、浏览器站点数据或缓存测试版的数据目录，也会清除这些本机备份。需要长期保留某个阶段的记录时，可另行导出 JSON 文件。

## 14. 注册与跨端云同步

### 第一次把本地记录放到云端

1. 先在本机添加或导入番剧。
2. 打开“设置 → 云同步”，填写邮箱和 8～128 个字符的密码，点击“注册”。
3. 注册成功后，使用该账号登录。
4. 如果云端尚无记录，点击“初始化云端”并确认，将本机列表上传到云端。

初始化只允许向空白云端上传，云端已有记录时会停止。

### 在另一台设备恢复记录

1. 在另一台设备打开“设置 → 云同步”，登录同一账号。
2. 点击“从云端恢复”并确认。
3. 云端非空时，记录会下载到当前设备。本机已有列表时，覆盖前先自动备份。

### 日常同步

登录后，本地修改、启动软件及重新联网时会尝试自动同步，也可以点击“立即同步”。离线时先保存本地修改，联网后再尝试上传。

普通同步保留空数据保护：本地列表为空时不可普通同步；云端为空时也不可普通同步。首次上传使用“初始化云端”，新设备下载使用“从云端恢复”。

### 处理冲突

两台设备都修改过记录时，设置页会显示冲突提示及云端上次同步时间：

- **使用云端：**用云端记录替换本机列表，替换前自动备份本机记录。
- **使用本地：**用当前设备记录覆盖云端，并保留原云端快照备份；若云端又被其他设备修改，会重新提示冲突。
- **导出双方 JSON：**先保存本地与云端两份内容，方便检查后再决定。

云同步保存番剧记录、观看进度、评分、感想和单集观看时间。主题、排序、提醒开关、自动备份和图片缓存属于各设备本机；换设备后需要分别设置，资料与缩略图会重新补齐。

登录状态失效时，重新登录即可。“退出登录”会结束当前设备的登录状态，本机番剧记录仍然保留。

## 15. 外观与不同版本的启动方式

在“设置 → 外观”中选择浅色或深色模式。

- **Windows 安装版：**运行安装程序，安装后从桌面或开始菜单启动。
- **Windows 免安装版：**打开完整程序文件夹，运行 `Anima List.exe`，保持程序与同目录文件在一起。记录和缓存保存在同目录 `portable-user-data` 中，日常关闭后再次启动会保留；重新部署更新包时会清空，更新前请导出 JSON，更新后导入或从云端恢复。
- **Windows 缓存测试版：**同样运行 `Anima List.exe`，记录和缓存保存在旁边的 `test-user-data` 文件夹中。移动测试版时，把该文件夹一起保留。
- **Android 版：**安装 APK 后，从桌面打开 Anima List。
- **网页版：**双击发布目录中的“启动网页版.cmd”，浏览器打开后即可使用；使用期间保留启动窗口，关闭窗口会停止本地网页服务。

网页版记录保存在当前浏览器中。换浏览器或换设备时，可通过 JSON 导入或云端恢复带回自己的记录。
